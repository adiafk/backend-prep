# Backend + AI Interview Preparation

A practical, resume-driven interview knowledge base for backend engineering, distributed systems, cloud infrastructure, databases, AI/LLM systems, TypeScript/Node.js, C++, DSA, and system design.

## How to use this repo

Every topic follows the same interview-first pattern:

1. Simple explanation
2. How it works
3. Example
4. Important terminology
5. Common mistakes
6. Interview questions + answers
7. Follow-up questions
8. Resume/project connection
9. Scaling, reliability, and security considerations

## Core resume themes

- Deterministic LLM evaluation/test harnesses
- Agent and tool-call orchestration
- Multi-provider LLM routing and failover
- Hybrid RAG with PostgreSQL/pgvector
- MongoDB + Redis performance optimization
- Bull queues, Kafka/Pub-Sub, event-driven systems
- Retry and failure recovery
- Token-bucket rate limiting
- JWT + Redis refresh-token rotation
- Google OAuth 2.0
- Idempotent payment webhooks
- AWS EC2/S3, Linode, PM2
- GitHub Actions CI/CD and rolling deployments
- Sentry/Grafana observability
